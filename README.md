# Collatz-45 Resonant Driver Visualizer

Interactive digital twin and real-time magnetic vortex simulation for the **Collatz-45 Resonant Driver (The Battery)**.

## Architecture Highlights
- **Geometry:** 8-fold toroidal magnetic chamber (45° phase spacing, pins 2–9).
- **Pulse Rhythm:** Non-linear Collatz `4 -> 2 -> 1` duty cycle (State 4 Potential, State 2 Slide, State 1 Dock).
- **Governor:** Intent Chord `0x6DAE0002` jitter modulation to eliminate standing-wave harmonic buildup.
- **Core Specification:** Fair-Rite Type 61 NiZn Ferrite for high-frequency low-loss magnetic rotation.

Built with Sontara & Faye for Cornelius.
